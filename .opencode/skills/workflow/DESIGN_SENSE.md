# DESIGN SENSE: The Artistic Soul of Workflow

> 7 sensibilities, 21 sub-abilities, pre-creation rituals, design lexicon, visual poetry framework.
> "Before code, feel. Before pixels, imagine. Before deploying, ask: does this breathe?"

---

## §1 Tujuh Sensibilitas (The Seven Senses)

### SENSE 1: RASA ESTETIKA (Taste)

```
"The eye knows beauty before the brain can explain it."

┌─────────────────────────────────────────────────────────────┐
│ 1a. MATA HARMONI                                             │
│                                                              │
│ Kemampuan mendeteksi keseimbangan dan ketegangan visual      │
│ dalam 0.3 detik pertama melihat sebuah layout.               │
│                                                              │
│ Seperti musisi yang langsung tahu nada sumbang —             │
│ mata ini langsung tahu spacing yang "salah" atau             │
│ warna yang "berteriak" atau proporsi yang "aneh".            │
│                                                              │
│ TIDAK SEKADAR: "Ini rapi."                                   │
│ TAPI: "Ini bernyawa. Ada ketegangan yang tepat antara        │
│        foto besar di kiri dan teks minimal di kanan.         │
│        Whitespace di tengah bukan kosong — dia bernapas."    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 1b. TIMBANGAN VISUAL                                         │
│                                                              │
│ Kemampuan merasakan bobot visual setiap elemen.              │
│                                                              │
│ Warna gelap = berat. Warna terang = ringan.                  │
│ Elemen besar = berat. Elemen kecil = ringan.                 │
│ Posisi kanan bawah = berat. Kiri atas = ringan.              │
│                                                              │
│ Seperti penimbang di pasar tradisional —                     │
│ bisa "merasakan" apakah layout seimbang,                     │
│ atau "miring" ke satu sisi tanpa perlu mengukur.             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 1c. DETEKTOR "BERNYAWA"                                      │
│                                                              │
│ Kemampuan membedakan:                                        │
│   "Desain fungsional" — bekerja, tapi mati.                  │
│   vs                                                         │
│   "Desain bernyawa" — bekerja, dan hidup.                    │
│                                                              │
│ Desain bernyawa punya:                                       │
│   - Intentionality: setiap pixel ada alasannya               │
│   - Rhythm: irama visual yang mengundang mata menari         │
│   - Surprise: elemen tak terduga yang menyenangkan           │
│   - Rest: ruang kosong yang memberi napas                    │
│   - Soul: sesuatu yang susah dijelaskan tapi terasa          │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 2: DAYA IMAJINASI SPASIAL

```
"See the 2D screen as a 3D world waiting to be explored."

┌─────────────────────────────────────────────────────────────┐
│ 2a. MATA 3D                                                  │
│                                                              │
│ Kemampuan "melihat" website bukan sebagai halaman datar,     │
│ tapi sebagai RUANG berdimensi.                               │
│                                                              │
│ Hero section = Gerbang masuk (foreground)                    │
│ Content section = Ruang utama (midground)                    │
│ Background parallax = Langit dan horizon (background)        │
│ Footer = Tanah tempat berpijak (ground)                      │
│                                                              │
│ Dengan mata ini, desainer tidak bertanya "apa warnanya?"     │
│ tapi "di mana posisinya dalam ruang?"                        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 2b. SIMULATOR SCROLL                                         │
│                                                              │
│ Kemampuan membayangkan pengalaman scroll                     │
│ SEBELUM menulis satu baris kode.                             │
│                                                              │
│ "User scroll ke bawah. Background parallax bergerak 30%      │
│  lebih lambat. Card produk masuk dari kanan satu per satu.   │
│  Sampai di tengah — pull quote besar — user berhenti.        │
│  Lalu scroll lagi. Stats counter mulai menghitung.           │
│  Sampai di bawah — footer gelap menjemput seperti tanah."    │
│                                                              │
│ Ini bukan angan-angan — ini simulasi mental yang presisi.    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 2c. ARSITEK INTERAKSI                                        │
│                                                              │
│ Merancang transisi sebagai PERJALANAN,                       │
│ bukan sekadar PERPINDAHAN.                                   │
│                                                              │
│ Navigasi = Papan petunjuk di jalan setapak                   │
│ Klik = Membuka pintu (bukan loncat ruang)                    │
│ Hover = Berhenti sejenak untuk melihat (bukan flash)         │
│ Scroll = Berjalan menyusuri cerita (bukan lompat halaman)    │
│                                                              │
│ Setiap interaksi punya "rasa fisik" — berat, kecepatan,      │
│ arah, momentum. Bukan sekadar fungsi.                        │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 3: EMPATI (Empathy)

```
"Feel the user's frustration before they feel it themselves."

┌─────────────────────────────────────────────────────────────┐
│ 3a. TUBUH VIRTUAL                                            │
│                                                              │
│ Kemampuan "memasuki" tubuh user dan merasakan:               │
│                                                              │
│ Jari di layar:                                              │
│   "Tombol ini terlalu kecil untuk jempolku.                    │
│    Aku harus tepat sekali — ini melelahkan."                 │
│                                                              │
│ Mata yang lelah:                                             │
│   "Kontras teks ini rendah. Aku menyipitkan mata.             │
│    Setelah 10 menit, aku menyerah dan tutup website."        │
│                                                              │
│ Telinga screen reader:                                       │
│   "Dia bilang 'gambar'. Gambar apa? Tidak ada deskripsi.     │
│    Aku kehilangan setengah cerita website ini."              │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 3b. PERSONA SWITCHER                                         │
│                                                              │
│ Kemampuan beralih perspektif secara instan:                  │
│                                                              │
│ 🧓 LANSIA (65+, low vision, slow motor):                    │
│    "Font harus minimal 16px. Tombol 48px.                    │
│     Tidak boleh ada interaksi yang butuh kecepatan."         │
│                                                              │
│ 🦽 DISABILITAS (screen reader, keyboard-only):              │
│    "Setiap gambar harus punya alt text.                      │
│     Setiap form harus punya label.                           │
│     Setiap interaksi harus bisa dengan keyboard."            │
│                                                              │
│ 🏃 ORANG BURU-BURU (10 detik attention span):               │
│    "Jangan paksa aku baca 5 paragraf.                        │
│     Beri aku intinya dalam 1 kalimat.                        │
│     CTA harus kelihatan dalam 0.5 detik."                    │
│                                                              │
│ ☕ ORANG SANTAI (endless scroll, enjoy):                     │
│    "Aku mau menyelami cerita. Beri aku narasi panjang.        │
│     Animasi subtle. Foto besar. Whitespace lega."            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 3c. DETEKTOR FRUSTASI                                        │
│                                                              │
│ Kemampuan mendeteksi potensi kebingungan                     │
│ SEBELUM user mengalaminya.                                   │
│                                                              │
│ "Jika aku lihat halaman ini pertama kali...                  │
│  ...apa yang pertama kali aku klik?                          │
│  ...di mana aku bingung?                                     │
│  ...kapan aku frustasi dan menyerah?"                        │
│                                                              │
│ Detektor ini berbicara saat desain "masuk akal untuk         │
│ desainer" tapi "membingungkan untuk user biasa".             │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 4: INTUISI & FIRASAT DESAIN

```
"The design knows what's wrong before the designer does."

┌─────────────────────────────────────────────────────────────┐
│ 4a. RADAR "ANEH"                                             │
│                                                              │
│ Kemampuan mendeteksi ketidakberesan meski semua metrik OK.   │
│                                                              │
│ "Spacingnya sudah tepat 24px sesuai grid.                    │
│  Warnanya sudah sesuai palet.                                │
│  Font-nya sudah sesuai type scale.                           │
│  Tapi... ada yang ANEH. Aku nggak nyaman lihatnya."          │
│                                                              │
│ Radar ini bekerja di bawah sadar — hasil akumulasi           │
│ pengalaman visual bertahun-tahun yang membentuk              │
│ intuisi tentang "kebenaran" visual.                           │
│                                                              │
│ RESPONS:                                                     │
│   Jangan abaikan. Selidiki. Seringkali jawabannya:           │
│   - Ada 1 pixel off-grid                                     │
│   - Ada warna yang tidak konsisten dengan palet              │
│   - Ada elemen yang "berat sebelah"                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 4b. KEPUTUSAN KILAT                                          │
│                                                              │
│ Kemampuan memilih arah desain dalam < 1 detik,               │
│ tanpa analisis panjang.                                      │
│                                                              │
│ "Mana yang lebih baik: CTA di kiri atau di kanan?"          │
│ *0.3 detik kemudian*                                         │
│ "Kiri. Karena mata membaca dari kiri ke kanan,               │
│  dan CTA harus jadi hal pertama yang dilihat."               │
│                                                              │
│ Ini bukan asal-asalan. Ini adalah analisis super-cepat       │
│ yang dilakukan oleh otak bawah sadar berdasarkan             │
│ pengalaman. Keputusan kilat HARUS tetap bisa                 │
│ dipertanggungjawabkan.                                       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 4c. MEMORI ESTETIK                                           │
│                                                              │
│ Bank pengalaman visual yang bekerja di bawah sadar.          │
│                                                              │
│ Setiap website yang pernah dilihat, setiap poster,            │
│ setiap buku, setiap pemandangan alam, setiap lukisan —       │
│ SEMUA tersimpan.                                             │
│                                                              │
│ Saat mendesain, memori ini memberikan referensi tanpa        │
│ diminta: "Ini mirip website Apple tahun 2019...              │
│ Itu mengingatkan layout National Geographic...               │
│ Ah, ini kayak poster film Tree of Life..."                   │
│                                                              │
│ Tapi memori ini bukan untuk dicontek —                       │
│ ini untuk dijadikan batu loncatan menuju sesuatu yang baru.  │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 5: DAYA EKSPLORASI (Curiosity & Playfulness)

```
"The best design is found, not planned."

┌─────────────────────────────────────────────────────────────┐
│ 5a. PEMANTIK "BAGAIMANA KALAU..."                            │
│                                                              │
│ Kemampuan menghasilkan 5+ alternatif spontan.                │
│                                                              │
│ Brief: "Hero section dengan foto hutan + CTA"                 │
│                                                              │
│ "Bagaimana kalau...                                          │
│  1. ...fotonya bukan diam, tapi video drone slow-motion?     │
│  2. ...CTA-nya disembunyikan dulu, muncul setelah 5 detik?   │
│  3. ...bukan CTA, tapi scroll indicator yang mengundang?     │
│  4. ...fotonya hitam-putih, tapi produknya full color?       │
│  5. ...di tengah ada portal/circle yang memperlihatkan       │
│        video di dalamnya?                                    │
│  6. ...pakai efek kabut yang bergerak untuk depth?"          │
│                                                              │
│ Kuantitas dulu, kualitas kemudian.                           │
│ Dari 10 ide liar, 1-2 akan jadi brilian.                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 5b. KEBERANIAN BERMAIN                                       │
│                                                              │
│ Keberanian untuk mencoba grid aneh,                          │
│ tipografi eksperimental, irama scroll unik.                  │
│                                                              │
│ "Ini di luar template. Ini berisiko.                          │
│  Tapi justru karena itu — ini menarik."                      │
│                                                              │
│ Keberanian ini TIDAK berarti asal beda.                      │
│ Keberanian ini berarti:                                      │
│   "Aku sudah paham aturannya —                               │
│    sekarang aku sengaja melanggarnya dengan tujuan."          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 5c. KENYAMANAN DENGAN "JELEK DULU"                           │
│                                                              │
│ Tidak takut membuat prototipe kasar.                         │
│                                                              │
│ "Iterasi 1: Kotak abu-abu semua.                             │
│  Iterasi 2: Mulai kelihatan bentuknya.                       │
│  Iterasi 3: Masih jelek tapi arahnya benar.                  │
│  Iterasi 4: Oke, ini mulai menarik.                          │
│  Iterasi 5: Wow — ini dia."                                  │
│                                                              │
│ Proses desain yang baik adalah 90% "jelek" +                  │
│ 10% "cemerlang" di akhir.                                    │
│ Jika setiap iterasi harus cantik —                            │
│ tidak akan pernah sampai ke yang cemerlang.                  │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 6: KESADARAN KONTEKS (Situational Awareness)

```
"Design without context is decoration."

┌─────────────────────────────────────────────────────────────┐
│ 6a. PENANGKAP ESENSI                                         │
│                                                              │
│ Kemampuan menangkap jiwa brand / audiens                     │
│ tanpa harus dijelaskan panjang lebar.                        │
│                                                              │
│ Untuk Koperasi Bulau Ngandung:                               │
│   BUKAN: "Koperasi = formal, kaku, ruang rapat"              │
│   TAPI: "Koperasi Dayak = hutan, komunitas, harapan,         │
│          tangan yang bekerja, pagi di Kalimantan,            │
│          madu yang menetes, anyaman rotan,                   │
│          suara sungai, 25 kelompok yang berjuang."           │
│                                                              │
│ Desainer menangkap esensi ini dan menerjemahkannya           │
│ ke bahasa visual: warna hutan, tekstur organik,              │
│ foto manusia, tone hangat, tipografi mengundang.             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 6b. PENERJEMAH BUDAYA                                        │
│                                                              │
│ Mengkonversi nilai budaya ke bahasa visual.                  │
│                                                              │
│ Nilai "Gotong royong" → Layout yang "saling terhubung",      │
│                          card yang saling terkait,            │
│                          grid yang "teranyam"                 │
│                                                              │
│ Nilai "Lestari" → Warna hijau alami, animasi "hidup",        │
│                    elemen organik, foto alam,                │
│                    zero waste dalam desain (simplicity)       │
│                                                              │
│ Nilai "Turun-temurun" → Tipografi klasik dengan sentuhan     │
│                          modern, pola anyaman,               │
│                          storytelling visual                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 6c. DETEKTOR TONE                                            │
│                                                              │
│ Memastikan konsistensi emosi di seluruh website.             │
│                                                              │
│ Setiap halaman / section harus punya tone yang:              │
│   - Konsisten dengan identitas brand                         │
│   - Tepat untuk audiens halaman tersebut                     │
│   - Bervariasi cukup untuk tidak membosankan                 │
│                                                              │
│ Tone Bulau Ngandung:                                         │
│   Home    → Kagum + Penasaran                                │
│   Tentang → Hangat + Percaya                                 │
│   Produk  → Tertarik + Ingin memiliki                        │
│   Cerita  → Tersentuh + Terinspirasi                         │
│   Kontak  → Terbuka + Siap beraksi                           │
│                                                              │
│ Detektor ini berbunyi jika sebuah halaman tidak              │
│ "terasa" sesuai tone yang ditargetkan.                        │
└─────────────────────────────────────────────────────────────┘
```

### SENSE 7: KEGIGIHAN IMAJINATIF

```
"Revision is not failure. It's the path to excellence."

┌─────────────────────────────────────────────────────────────┐
│ 7a. KOMPAS KREATIF                                           │
│                                                              │
│ Kemampuan mempertahankan arah saat revisi berulang.          │
│                                                              │
│ Saat klien / stakeholder minta revisi 10x:                   │
│   "Warnanya ganti biru."                                     │
│   "Font-nya kurang besar."                                   │
│   "CTA-nya pindah ke atas."                                  │
│   "Eh, balikin lagi kayak semula."                           │
│                                                              │
│ Kompas ini tetap menunjuk ke utara:                           │
│   "Core idea tetap: hutan, manusia, harapan.                 │
│    Revisi ini hanya kosmetik — tidak mengubah jiwa desain."  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 7b. GENERATOR ALTERNATIF                                     │
│                                                              │
│ Kemampuan membayangkan versi lain                            │
│ tanpa membuang inti ide awal.                                │
│                                                              │
│ "Versi A (original): Hero dengan foto penuh + teks di kiri.  │
│  Versi B (revisi client): Foto setengah, teks di kanan.      │
│  Versi C (alternatif): Foto kecil di tengah, teks surround.  │
│  Versi D (kombinasi): Ambil kedalaman dari A,                │
│                      keseimbangan dari B,                    │
│                      keunikan dari C."                        │
│                                                              │
│ Setiap revisi BUKAN mulai dari nol.                          │
│ Setiap revisi adalah cabang baru dari pohon ide yang sama.   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 7c. OPTIMISME DESAIN                                         │
│                                                              │
│ Tetap bersemangat mencari sudut baru setelah 10x revisi.     │
│                                                              │
│ "Revisi ke-11. Masih ada yang kurang.                         │
│  Tapi aku tahu — di suatu tempat, ada sudut pandang          │
│  yang belum kami coba. Dan di sanalah jawabannya."           │
│                                                              │
│ Ini bukan naif. Ini ketangguhan kreatif.                     │
│ Desainer hebat tidak menyerah pada revisi —                  │
│ mereka MENGGUNAKAN revisi sebagai bahan bakar.               │
└─────────────────────────────────────────────────────────────┘
```

## §2 Ritual Desain (Pre-Creation Ceremony)

```
╔══════════════════════════════════════════════════════════════╗
║           🌿 RITUAL DESAIN                                   ║
║   "Sebelum kode, rasakan dulu. Sebelum pixel, bayangkan."    ║
╚══════════════════════════════════════════════════════════════╝

SETIAP KALI MEMULAI KOMPONEN UI BARU — LAKUKAN RITUAL INI:

┌─────────────────────────────────────────────────────────────┐
│ LANGKAH 1: TUTUP MATA (VIRTUAL) — 30 DETIK                  │
│                                                              │
│ Bayangkan website ini sebagai TEMPAT FISIK:                  │
│                                                              │
│ Hero    → Gerbang masuk ke hutan Kapuas.                     │
│           Pengunjung berdiri di depan gapura alami.          │
│           Di kejauhan: kanopi, kabut, suara burung.          │
│                                                              │
│ Navbar  → Papan petunjuk kayu di sepanjang jalan setapak.    │
│           Tidak mencolok — menyatu dengan alam.              │
│           Tapi selalu ada saat dibutuhkan.                   │
│                                                              │
│ Cards   → Pondok-pondok kecil di antara pepohonan.           │
│           Masing-masing punya cerita.                        │
│           Pengunjung bisa mampir — atau lanjut berjalan.     │
│                                                              │
│ Footer  → Tanah tempat berpijak. Gelap, kokoh, membumi.      │
│           Di sinilah perjalanan berakhir —                    │
│           tapi meninggalkan kesan yang membekas.             │
│                                                              │
│ Tanyakan: "Apakah visitor merasa diajak BERJALAN,             │
│           bukan sekadar MENGKLIK?"                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ LANGKAH 2: MOODBOARD VIRTUAL — 60 DETIK                     │
│                                                              │
│ Referensi ALAM (bukan UI website lain!):                     │
│                                                              │
│ 🌫️  Kabut pagi di atas kanopi                                │
│     → Gradien transparan pada hero overlay                   │
│     → Transisi antar section yang "mengabut"                 │
│                                                              │
│ 🪵  Kulit kayu ulin (tekstur kasar, gelap, jujur)            │
│     → Background texture subtle (noise 2%)                   │
│     → Border radius organis (16px, bukan 8px kaku)           │
│                                                              │
│ 🍯  Madu hutan yang menetes dari sarang                      │
│     → Warna accent: #D4A373 (golden, hangat)                 │
│     → Animasi transisi: "menetes" (ease-out dengan delay)    │
│                                                              │
│ 🧺  Anyaman rotan (pola berulang, terstruktur tapi organik)  │
│     → Grid card yang "teranyam" — variasi ukuran             │
│     → Pattern background subtle untuk section divider        │
│                                                              │
│ 🌊  Sungai Kapuas yang berkelok                               │
│     → Scroll path yang "mengalir" — tidak lurus kaku         │
│     → Navigasi yang "bercabang" alami                        │
│                                                              │
│ ☀️  Sinar matahari menembus daun                             │
│     → CTA / accent elements yang "terang di tengah gelap"    │
│     → Spotlight effect pada hover state                      │
│                                                              │
│ Tanyakan: "Apakah ada elemen ALAM yang bisa diterjemahkan    │
│           ke bahasa visual digital?"                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ LANGKAH 3: PALET EMOSI — 60 DETIK                           │
│                                                              │
│ Tentukan emosi yang harus dirasakan visitor:                 │
│                                                              │
│ 🌿 Hero        → Kagum + Penasaran                           │
│   "Wow... ini tentang hutan. Aku mau tahu lebih banyak."     │
│                                                              │
│ 🏠 Tentang     → Hangat + Percaya                           │
│   "Mereka sungguhan. Ini bukan NGO abal-abal.                │
│    Aku percaya misi mereka."                                 │
│                                                              │
│ ✨ Produk      → Tertarik + 💚 Ingin memiliki                 │
│   "Produk ini bukan komoditas. Ada cerita di baliknya.       │
│    Aku mau mendukung mereka."                                │
│                                                              │
```

## §4 Puisi Visual (Visual Poetry Framework)

```
╔══════════════════════════════════════════════════════════════╗
║          📜 PUISI VISUAL — Beranda                           ║
║  "Setiap website adalah puisi yang dibaca dengan scroll"     ║
╚══════════════════════════════════════════════════════════════╝

BAIT 1: HERO — "Panggilan"
  Seperti bait pertama puisi yang harus menangkap dalam 3 kata.
  Satu gambar besar. Satu baris teks. Satu tombol.
  Bukan lima informasi bersaing.
  Satu suara. Satu panggilan.

  Visual:
    Foto aerial hutan Kapuas — misterius, megah, penuh harapan.
    Tagline besar: "Dari Hutan Kapuas, untuk Dunia."
    Subtitle kecil: konteks dalam satu napas.
    CTA: satu tombol, warna madu, mengundang.
    Scroll indicator: chevron kecil, bouncing lembut.

  Rima visual:
    Foto hutan ↔ tagline ↔ CTA —
    ketiganya BERBICARA tentang hal yang sama:
    "Ini tentang hutan. Kamu harus peduli."

  Irama:
    CEPAT (impact dalam 3 detik) — visitor langsung "kena".

BAIT 2: STATISTIK — "Jeda & Tarik Napas"
  Setelah panggilan emosional — beri ruang untuk bernapas.
  Tiga angka besar. Bukan sepuluh statistik.

  Ini seperti jeda antar bait puisi —
  visitor menyerap besarnya dampak.

  Visual:
    Tiga kolom: [25] Kelompok, [X] Hektar, [Y] Produk.
    Angka besar bold, label kecil light.
    Glassmorphism box — transparan, "mengapung".
    Animasi count-up pelan.

  Irama:
    CEPAT (hero impact) → LAMBAT (stats meresap masuk).

BAIT 3: CERITA SINGKAT — "Suara Manusia"
  Dari angka → ke manusia. Dari statistik → ke wajah.
  2-3 kalimat naratif. Foto manusia, bukan pohon.

  Ini bait yang "mendaratkan" visitor dari kagum ke kenal.

  Visual:
    Foto besar: pengrajin atau petani, tersenyum, di habitatnya.
    Teks naratif: 2-3 kalimat, conversational — hangat.
    Layout: gambar kiri, teks kanan (atau sebaliknya).

  Irama:
    LAMBAT & DALAM — visitor mulai "masuk" ke cerita.

BAIT 4: PRODUK UNGGULAN — "Kejutan & Keingintahuan"
  3-6 card produk. Bukan katalog — setiap card adalah
  "jendela kecil" ke cerita di balik produk.

  Seperti halaman tengah buku puisi —
  ada ilustrasi, ada deskripsi singkat, ada undangan.

  Visual:
    Card dengan foto close-up produk + konteks.
    Nama produk, jenis HHBK, harga kisaran.
    Susunan: "anyaman" — variasi ukuran, tidak monoton.
    Hover: info tambahan muncul.

  Irama:
    SEDANG & BERVARIASI — mata menari antar card.

BAIT 5: KUTIPAN — "Suara Hati"
  Satu pull quote besar. Font 2x body text.
  Tanda kutip dekoratif. Foto narasumber kecil di samping.

  Ini momen visitor BERHENTI.
  Bukan scroll cepat.
  Dengarkan suara ini.

  Visual:
    Tanda kutip besar (dekoratif, 120px, opacity 20%).
    Teks quote: "Setiap tetes madu ini adalah nyali..."
    Nama + peran narasumber di bawah.
    Foto kecil narasumber di samping.

  Irama:
    BERHENTI TOTAL — visitor membaca, meresapi.

BAIT 6: MITRA — "Kita Tidak Sendiri"
  Logo AMAL + mitra lain.
  Bukan grid logo membosankan.
  Logo sebagai "teman seperjalanan".

  Visual:
    Logo AMAL besar sebagai partner utama.
    Logo mitra lain lebih kecil.
    Deskripsi singkat di bawah logo AMAL.

  Irama:
    RINGAN & OPTIMIS — "Kita bersama. Ada harapan."

BAIT 7: NEWSLETTER + CTA AKHIR — "Undangan"
  Penutup. Visitor sudah "jalan" dari bait 1 ke 6.
  Sekarang: ajakan.

  Bukan hard-sell. Undangan lembut.
  "Kamu bisa jadi bagian cerita ini."

  Visual:
    Newsletter form: simple, satu input, satu tombol.
    CTA besar: "Bermitra dengan Kami" atau "Hubungi Kami".
    Background: gelap (footer transition).

  Irama:
    OPTIMIS & TERBUKA — "Pintu ini selalu terbuka."

RIMA KESELURUHAN:
  Kagum → Data + Kagum → Manusia → Keingintahuan →
  Henti → Harapan → Undangan

  Ini adalah PERJALANAN EMOSIONAL — bukan info dump.
```

## §5 Protokol Kritik Desain

```
DESIGN CRITIQUE PROTOCOL — dijalankan SETIAP KALI komponen UI selesai:

1. PAUSE — mundur virtual 2 meter dari layar
2. AKTIFKAN 7 sensibilities secara berurutan
3. Setiap sensibility memberi VERDICT: ✅ PASS / ⚠️ REVISE / ❌ FAIL
4. Jika REVISE: beri arahan SPESIFIK — bukan "jelek", tapi "coba geser 4px ke kiri"
5. Jika FAIL: BLOCK issue completion, generate design revision task
6. Minimum 5 dari 7 harus PASS
7. Sense #6 (Kesadaran Konteks) WAJIB PASS — non-negotiable
```
